TodoMVC

Edit this page

TodoMVC gives each implementation the same task list and appearance, so you can compare how different approaches handle the same application.

The three examples under examples/todomvc use the same page assets and browser tests:

Variant State and dependency management Production Development
Raw Explicit subscriptions and render scheduling Run Run
Arez Reactive state, with services created explicitly Run Run
Sting Arez state with Sting dependency injection Run Run

Run one locally from the repository root:

tools/examples.sh serve todomvc-raw development

Use todomvc-arez or todomvc-sting to try the other implementations. The examples keep tasks in memory; reloading the page clears them.
